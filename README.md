# 🌿 DesiVora

### Mindful Living • Curated Goods • Modern Shopping

DesiVora is a modern e-commerce website created for people who love simple, thoughtful, and beautifully curated lifestyle products.

## ✨ What You Can Do

- 🛍️ Explore curated products
- 🔍 View product details
- 🛒 Add items to your cart
- ❤️ Save products to your wishlist
- 👤 Create an account and log in
- 📱 Enjoy a responsive experience on any device

## 🛠️ Built With

**Frontend:** HTML,CSS and Javascript  
**Backend:** Node.js, Express.js  
**Database:** MongoDB
